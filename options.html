Deslop the Web — settings

Shared slop list

The list is loaded from this URL and refreshed every 6 hours. If it can't be reached, the last good copy is used, and before the first download, the copy bundled with the extension. Leave the field empty to use only the bundled copy.

Custom slop phrases

These are only yours, added on top of the shared list, one per line. A plain phrase matches as whole words, case-insensitive, with a default weight of 3 (a single hit collapses the paragraph at "Balanced"). Set a weight with phrase | 2. For a regex, use /regex/ | 4. Lines starting with # are comments.

Thresholds


Whole-page warning

Thinly spread slop never trips the per-paragraph check, so the page is also judged as a whole. For calibration, adrs.systems scores 9.3 points per 100 words and normal human writing scores about 0.1–0.2.



Inline snips

Filler fragments such as ", always", ", verbatim" or ", exactly as it sits in the repository" are cut in place, headings included, and replaced by a small ✂ button that reveals them. Single words ("quietly", "genuinely", "Honestly,") are only cut in collapsed paragraphs and on pages that already look suspicious overall.

Your own snips, one per line, same syntax as above (the weight is ignored). Include the leading comma or dash you want gone, e.g. /,\s*no notes(?=[.!])/.

Disabled sites

One hostname per line, e.g. news.ycombinator.com.
