## deslop-list v1
# Shared slop list for the Deslop the Web Firefox extension.
#
# Format, one entry per line:
#   [patterns]  weight | label | regex
#   [snips]     scope | label | regex
# Fields are separated by " | " (space, bar, space); the regex is everything after the
# second separator, written raw (no escaping), compiled case-insensitive with the u flag.
# Use ['’] for apostrophes, since sites mix straight and curly quotes.
#
# Pattern weights: 3+ near-certain slop (one hit collapses at default sensitivity),
# 2 strong, 1 weak (common in human writing too, only counts in bulk).
# Snip scopes: always = filler wherever it appears; sloppy = only in collapsed
# paragraphs or on pages that look suspicious overall. A snip's match is exactly
# the text that gets cut, so include the leading comma or dash.
#
# Before sending a change: npm test (checks slop pages are caught and human pages are not).
